# Views

一个 view 把散在各处的页按 `type` 收拢成一张表。表本身不是知识，只是入口。

- [[views/concept.base|Concepts]] — 区分与它的对照
- [[views/person.base|People]] — 谁在这里，持什么
- [[views/argument.base|Arguments]] — 结论是否成立
- [[views/source.base|Sources]] — 一章说了什么，在哪
- [[views/book.base|Books]] — 一本书的进度与产出
- [[views/take.base|Takes]] — 我自己的立场
